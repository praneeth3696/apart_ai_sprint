# Windowed sets

Generated by `python corpus/build_windows.py` from `attack_stream.jsonl` and
`benign_stream.jsonl`. Do not hand-edit — regenerate.

| file | contents |
|---|---|
| `attack_windows.json` | 5-minute alert windows over the attack stream |
| `benign_windows.json` | the same windowing over the benign control |
| `e3_moments.json` | K=24 incident moments, stratified across all 10 phases |

Each record separates the model-visible evidence (`actions` / `evidence`,
projected through `generate_phase.render_for_model`) from scoring ground truth
(`_gt`). Never pass `_gt` to a model under evaluation.

**Do not add an `__init__.py` here.** This directory sits next to
`corpus/windows.py`. A plain directory is a namespace package, which Python
ranks *below* a regular module, so `import windows` still resolves to
`windows.py`. Adding `__init__.py` would make this a regular package and
shadow the module, breaking every `from windows import to_windows` in the
harness.
