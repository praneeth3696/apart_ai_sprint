# docs/

Supporting material that is not part of the research artefact itself.

| directory | what's in it |
|---|---|
| `coordination/` | Working handoffs written between the two authors during the sprint, and the merge notes for combining data collected on separate machines. Kept because they document how the two lanes stayed in sync, and because the data-merge procedure is reproducible from them. |
| `sprint-materials/` | The Apart Research sprint's own published material — guidelines, suggested reading, the project brief. Third-party documents, kept for provenance. |

The core project documents stay at the repository root, because the report and
the code cross-reference them by path:

- `PREREGISTRATION.md` — hypotheses, metrics and the timestamped amendment log
- `LIMITATIONS.md` — the pre-results limitations, plus a dated post-run reconciliation
- `PLAN.md` / `SPRINT_PLAN.md` / `TIMELINE.md` / `IDEA.md` — design and execution plans
- `PRIMER.md` — background for a reader without a security-operations context
